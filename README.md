# Portfolio.OS — Arthur Costa

Portfólio pessoal com visual de sistema operacional fictício, desenvolvido em HTML, CSS e JavaScript puro.

## Funcionalidades
- Boot automático animado (sem botão de pular)
- Desktop responsivo, sem barra de tarefas
- Janelas de Sobre mim, Projetos, Tecnologias, Trajetória, Currículo e Contato
- Fechar janelas pelo botão × ou pela tecla Escape
- Links públicos para MathLab, Essence, GitHub e LinkedIn
- Visualização e download do currículo em PDF
- Suporte a preferência por movimento reduzido

## Como executar
Copie o conteúdo dos arquivos .txt para os respectivos arquivos do projeto no IntelliJ, removendo a extensão .txt. Copie também o PDF para `assets/documents/Currículo Arthur.pdf`. Abra `index.html` no navegador.

## Publicação
Envie os arquivos para o GitHub e ative Settings > Pages > Deploy from a branch, escolhendo a branch principal e a pasta raiz.

**Privacidade:** o PDF incluído é o currículo original e contém endereço residencial. Substitua-o por uma versão pública sem endereço antes de publicar. O telefone e e-mail de contato também ficarão visíveis no site público.
